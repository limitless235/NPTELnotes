# notes-2 — transcript-grounded lecture notes

A second notes series for **Cyber Security and Privacy** (NPTEL 106106248, Prof. Saji K. Mathew). These notes follow the YouTube captions lecture by lecture. They are meant to cover **what the videos actually teach** (cases, formulas, Q&A definitions, instructor corrections), not a generic textbook restatement.

The original volume notes remain in [`../notes/`](../notes/).
