# notes-3 writing style (Cyber Security Tools · IGNOU)

These notes are **exam-concept notes**, not lab manuals. Source reference is the course **`pdf/`** volume set (not notes-2).

## Keep

- Definitions: what a tool/topic *is*
- Roles: what it *does* / why it exists
- Short comparison tables (tool categories, STRIDE, IT Act sections, frameworks)
- Named phases / frameworks in order (Kill Chain, PCI-DSS, NIST CSF, …)
- One-line defenses and exam lines

## Drop

- Full command lines and flag encyclopedias
- Install / UI click-paths (ZAP proxy ports, GVM setup, SET menu paths)
- Long attack procedures and payload lists
- Lab IP addresses and DVWA walkthroughs

## Per lecture skeleton

```markdown
## Lxx: Title

### What it is / what it does
- ...

### Defenses (one-liners)
- ...

### Exam lines
- ...
```
