# notes-3 writing style (Ethical Hacking)

These notes are **exam-concept notes**, not transcript dumps and not lab manuals.

## Keep

- Definitions: what X *is*
- Roles: what X *does* / why it exists
- Short comparison tables (TCP vs UDP, RIP vs OSPF vs BGP, virus vs worm vs trojan, …)
- Named phases / frameworks in order (pentest lifecycle, DORA, handshake, …)
- One-line defenses and exam lines

## Drop

- Full command lines and flag encyclopedias
- Install / UI click-paths (Nessus plugin compile times, localhost ports unless asked in syllabus)
- Long attack procedures and Metasploit module walk-throughs
- Stats, vendor marketing, and filler ASR text from notes-2

## Per lecture skeleton

```markdown
## Lxx: Title

### What it is / what it does
- ...

### Defenses (one-liners)
- ...

### Exam lines
- ...
```
